## ▶️ YouTube Import — Full Videos or Timestamped Clips

</div>

> Paste an Instagram Reel or YouTube link into the same import box. Make Shorts detects the platform automatically. If it is YouTube, timestamp controls appear so you can import only the part you need — or import the entire video.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Paste Link: https://youtu.be/...                                             │
│                                                                              │
│  ✅ YouTube detected                                                         │
│                                                                              │
│  Start: 00:15        End: 00:45                                              │
│                                                                              │
│  [ Import Clip ]       [ Import Entire Video ]                               │
└──────────────────────────────────────────────────────────────────────────────┘
```

### Supported YouTube Links

| Format | Example |
|--------|---------|
| Standard videos | `https://www.youtube.com/watch?v=VIDEO_ID` |
| Short links | `https://youtu.be/VIDEO_ID` |
| YouTube Shorts | `https://youtube.com/shorts/VIDEO_ID` |
| Mobile links | `https://m.youtube.com/watch?v=VIDEO_ID` |
| Time links | `https://youtu.be/VIDEO_ID?t=45s` |

### YouTube Import Features

- Auto-detects YouTube vs Instagram links.
- Supports full video import.
- Supports timestamped clip import using seconds, `MM:SS`, or `HH:MM:SS`.
- Prefills start time from YouTube `t=` links when available.
- Extracts audio from full YouTube videos or selected timestamp ranges.
- Lets imported YouTube media work like any local video/audio asset in Studio.
- Supports captions/transcription on imported YouTube clips.
- Can save imported YouTube clips/audio into Creator Vault when enabled.

## 🧼 Caption Cleaner + 🪄 Image Object Eraser

</div>

<br/>

<details open>
<summary><b>🧼 Caption Cleaner</b></summary>

Caption Cleaner handles two cases:

- **Generated captions:** hide, delete, or exclude the app-generated caption track from export.
- **Baked-in captions:** select a top/center/bottom/custom region and clean it using local ffmpeg/OpenCV-style processing.

Useful controls include:

- Region preset: `top`, `center`, `bottom`, or custom rectangle.
- Method: delogo, blur, fill/cover, or inpainting when available.
- Output is saved as a new cleaned media asset so the original is never overwritten.

</details>

<details>
<summary><b>🪄 Image Object Eraser</b></summary>

- Select an image asset or image overlay in Studio.
- Paint a mask over the unwanted object/distraction.
- Locally process the image using OpenCV-style inpainting when available.
- Save the cleaned result as a new image asset.
- Add the cleaned image back to Studio or Creator Vault.

</details>

```bash
cd /Users/azhaankhan/Downloads/make_shorts
```

```bash
python ui/app.py
```

```text
http://127.0.0.1:5000/studio
```

```bash
python make_shorts.py "your topic"

python make_shorts.py --script my_script.txt --images ./my_photos/
```

## 🧭 API Endpoints

</div>

These endpoints are intended for local automation or for integrating Make Shorts with simple scripts. Endpoint names may vary slightly depending on the current branch, but the supported feature groups are listed below.

<br/>

| Method | Endpoint | Purpose |
|--------|----------|---------|
| `POST` | `/api/instagram/fetch` | Accepts JSON `{ "url": "..." }` or `{ "urls": ["...", "..."] }`. Returns a `results` array with `{ filename, duration, preview_url }` for each fetched Reel. |
| `POST` | `/api/instagram/transcribe` | Accepts `{ "url": "..." }`. Returns `{ filename, duration, audio_duration, transcript }`. |
| `POST` | `/api/instagram/assemble` | Form POST used by the UI to render the final video. Returns `{ job_id }` to poll with `/api/status/&lt;job_id&gt;`. |
| `GET` | `/api/status/&lt;job_id&gt;` | Returns job progress including `status`, `message`, and `percent` from `0` to `100`. |
| `POST` | `/api/instagram/trim` | Accepts JSON `{ "filename": "...", "start": 3.2, "end": 12.5 }`. Returns `{ filename, preview_url }` for the trimmed result. |
| `POST` | `/api/media/detect-link` | Detects whether a pasted link is Instagram, YouTube, or unsupported. |
| `POST` | `/api/media/fetch` | Imports a full Instagram/YouTube media source using auto-detected platform logic. |
| `POST` | `/api/media/clip` | Imports a timestamped clip from YouTube or other supported media sources. |
| `POST` | `/api/media/audio-extract` | Extracts audio from an Instagram/YouTube video or selected YouTube timestamp range. |
| `POST` | `/api/youtube/fetch` | YouTube-specific full-video import endpoint if implemented separately. |
| `POST` | `/api/youtube/clip` | YouTube-specific timestamp clip endpoint if implemented separately. |
| `POST` | `/api/youtube/audio-extract` | YouTube-specific audio extraction endpoint if implemented separately. |
| `GET` | `/studio` | Serves the Studio multi-track timeline video editor. |
| `GET` | `/api/studio/projects` | Lists all saved Studio project sessions with their details. |
| `POST` | `/api/studio/project/create` | Initializes a new blank Studio project JSON state. |
| `GET` | `/api/studio/project/&lt;id&gt;` | Loads the project timeline JSON configuration. |
| `POST` | `/api/studio/project/&lt;id&gt;/save` | Saves the project timeline state, including tracks, clips, text overlays, and assets. |
| `POST` | `/api/studio/media/upload` | Uploads local video/audio/image assets to Studio storage and extracts duration/metadata. |
| `POST` | `/api/studio/render` | Composites the multi-track timeline into a final 1080×1920 MP4 using MoviePy/FFmpeg. Returns `{ job_id }`. |
| `GET` | `/api/library/assets` | Lists Creator Vault assets with optional search/filter/favorite filters. |
| `POST` | `/api/library/assets/add` | Adds an existing local file into Creator Vault and registers metadata. |
| `POST` | `/api/library/assets/&lt;asset_id&gt;/rename` | Renames a Creator Vault asset display name. |
| `POST` | `/api/library/assets/&lt;asset_id&gt;/favorite` | Toggles or sets the favorite state for a Vault asset. |
| `POST` | `/api/tools/caption-cleaner/video` | Cleans baked-in captions from a selected video region or creates a cleaned copy. |
| `POST` | `/api/tools/image-eraser` | Applies mask-based image object erasing and returns a cleaned image asset. |
| `POST` | `/api/tools/remove-silence` | Creates a jump-cut asset by removing silent/dead-air ranges. |
| `GET` | `/api/caption-presets` | Returns kinetic caption preset definitions if exposed through API. |
| `GET` | `/api/layout-presets` | Returns split-screen / TikTok Brain layout templates if exposed through API. |
| `POST` | `/api/clear-storage` | Clears local storage directories used by the app such as `uploads/`, `temp/`, `output/`, `sessions/`, `music/`, and `gameplay/`. |

<div align="center">

## ⚠️ Troubleshooting

</div>

<br/>

<details open>
<summary><b><code>moviepy.editor</code> import issue</b></summary>

If `python ui/app.py` fails with `No module named 'moviepy.editor'`, install the requirements and try again.

```bash
pip install -r requirements.txt
```

</details>

<details>
<summary><b>Ollama issues</b></summary>

Start Ollama before using AI Mode:

```bash
ollama pull llama3.2
ollama serve
```

Or run the service/open the desktop app and pull the model:

```bash
ollama serve
# or open the Ollama desktop app
ollama pull llama3.2
```

</details>

<details>
<summary><b>ffmpeg not found</b></summary>

```bash
# Mac
brew install ffmpeg
export PATH="/opt/homebrew/bin:$PATH"

# Linux
sudo apt install ffmpeg
```

</details>

<details>
<summary><b>YouTube video unavailable or private</b></summary>

- Confirm the YouTube link is public and reachable.
- Try a normal video, Shorts link, and `youtu.be` link to isolate the issue.
- Update `yt-dlp` if downloads fail repeatedly.

```bash
pip install -U yt-dlp
```

</details>

<details>
<summary><b>Invalid YouTube timestamp</b></summary>

Use seconds, `MM:SS`, or `HH:MM:SS`.

Examples:

```text
15
00:15
01:30
00:01:30
```

The end timestamp must be after the start timestamp.

</details>

<details>
<summary><b>Creator Vault asset not showing</b></summary>

- Refresh Studio and reload the Vault panel.
- Confirm the asset file exists in `media_library/`.
- Check `media_library/assets.json` for the asset metadata.
- Use supported file types such as MP4, MP3, WAV, JPG, and PNG.

</details>

<details>
<summary><b>Object Eraser dependency missing</b></summary>

If object erasing fails, install OpenCV support if it is part of the feature branch:

```bash
pip install opencv-python-headless
```

If OpenCV is optional in your branch, use the fallback blur/fill cleanup mode.

</details>

<details>
<summary><b>Silence remover creates weird cuts</b></summary>

- Lower the silence threshold if too much is removed.
- Increase minimum silence duration if cuts are too aggressive.
- Add padding before/after speech to keep words natural.
- Test on shorter clips first.

</details>

<details>
<summary><b>Kinetic captions render slowly</b></summary>

Word-level animations can be render-heavy. Speed tips:

- Use shorter clips while testing.
- Disable word pop for draft exports.
- Lower FPS to `24`.
- Use simpler caption presets for long videos.

</details>

<details>
<summary><b>Apple/SF font not showing on non-Apple systems</b></summary>

The app uses the system font stack:

```css
-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", Arial, sans-serif
```

On non-Apple systems, it falls back to Helvetica/Arial or the closest available sans-serif font.

</details>

<details>
<summary><b>Video looks blank / dark</b></summary>

Gameplay download may have failed. Use **Manual Mode** and upload your own MP4, or check your internet connection.

</details>

<details>
<summary><b>Render is slow</b></summary>

Normal for local CPU rendering. A 50s Short can take a few minutes.

Speed tips:

- Set `WHISPER_MODEL = "tiny"` in `make_shorts.py`
- Lower `FPS` to `24`
- Keep Studio projects short when iterating
- Reduce overlay/filter/kinetic caption complexity before final export

</details>
